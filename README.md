# Expense Tracker API

Controle financeiro pessoal com registro de receitas e despesas, categorias e resumo de saldo. Consultas por período e relatório financeiro por usuário.

## Tecnologias
Java 17 · Spring Boot 3.2 · Spring Data JPA · PostgreSQL · Maven · Swagger/OpenAPI

## Funcionalidades
- Registro de receitas (INCOME) e despesas (EXPENSE)
- Categorias customizáveis por lançamento
- Filtro por período com `LocalDate`
- Resumo financeiro: total receitas, total despesas, saldo
- Consulta por usuário

## Como Executar
```bash
mvn spring-boot:run
# Acesse: http://localhost:8092/swagger-ui.html
```
